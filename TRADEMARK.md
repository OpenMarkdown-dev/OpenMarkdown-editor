## What you can do without asking

- Say that your product **uses**, **embeds** or **is built on** `@openmarkdown-dev/editor`, or
  that it is "powered by OpenMarkdown Editor". Use the name in plain text, as a fact.
- Publish a fork of this code under the MIT license. Refer to the original as
  "OpenMarkdown" when you describe where it came from.
- Write about the project (articles, talks, comparisons, tutorials) using the name.

## What needs written permission

- Naming a product, fork, package, company or domain "OpenMarkdown", or anything that
  could be confused with it (`openmarkdown-pro`, `OpenMarkdown Editor X`, a look-alike logo).
- Using the logo, except to link to the project.
- Implying that the OpenMarkdown project endorses, sponsors or maintains your product.

A fork that is distributed to others must use a different name and must not use the logo.
