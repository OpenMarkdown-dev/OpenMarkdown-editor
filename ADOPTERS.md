# Adopters

Projects that use `@openmarkdown-dev/editor`, added by the people who build them.

To add yours, open a pull request that adds one line under **Projects**:

```
- [Project name](https://link.to/project) — what it uses the editor for, in one sentence.
```

A logo is optional: put it in `adopters/` and add ` · logo: adopters/<file>` at the end of the line. Merging your pull request is your consent to be listed on this file and on openmarkdown.dev/editor. Nobody is added on their behalf.
