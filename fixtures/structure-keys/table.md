# 源码模式的表格

结构键黄金用例(spec: structure-input)。`‸` 是光标,`«…»` 是选区(Tab 跳格后选中整格内容)。

## Tab 跳到下一格
keys: Tab

```md
| a | b |
| --- | --- |
| 1‸ | 2 |
```

```md
| a | b |
| --- | --- |
| 1 | «2» |
```

## Shift-Tab 跳到上一格
keys: Shift-Tab

```md
| a | b |
| --- | --- |
| 1 | 2‸ |
```

```md
| a | b |
| --- | --- |
| «1» | 2 |
```

## 末格 Tab 追加一行
keys: Tab

```md
| a | b |
| --- | --- |
| 1 | 2‸ |
```

```md
| a   | b   |
| --- | --- |
| 1   | 2   |
|     ‸|     |
```

## 表格里 Enter 是普通换行
keys: Enter

```md
| a | b |
| --- | --- |
| 1 | 2‸ |
```

```md
| a | b |
| --- | --- |
| 1 | 2
‸|
```
